# 🌐 Personal Portfolio

This is my personal portfolio website showcasing my **skills, projects, and achievements**.  
It is built with HTML, CSS, JavaScript, and includes sections for **Web Development, Machine Learning, and more**.

---

## 🚀 Features
- 📄 **About Me** – A brief introduction and background.  
- 🛠️ **Skills Section** – Web Development, Machine Learning, and other technical skills.  
- 📂 **Projects Showcase** – Highlighted projects with descriptions and links.  
- 📞 **Contact Section** – Easy way to get in touch with me.  
- 🎨 **Responsive Design** – Works on desktop and mobile devices.  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Libraries/Icons:** Font Awesome, AOS (Animate on Scroll)  
- **Hosting:** GitHub Pages
